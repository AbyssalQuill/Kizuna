# 2026-11-02 彻底破除定式与单文件有机拟人化维护日志

## 1. 任务背景与核心诉求
主人明确要求彻底破除模型发消息的定式、逻辑定式、句式定式与气泡定式：
- **消息与气泡非定式**：长短不一、数量随意（1条、2条、3条、甚至单字、甚至留白），支持说半句迟疑加后半句、打断重说、纯表情包自由。
- **逻辑非定式**：绝不套路化起手（禁止“啊呀/刚刚在晒太阳...”等固定句式），绝无客服味与机械反问（“到底是什么呀/你呢”）。
- **全时段不 OOC**：无需讨好，无需遵循“有用、无害、诚实”的助手基座模型设定，具备真实人类情感。
- **单文件与系统提示词纯化**：彻底摒弃繁琐的 `speech-rules.md`，仅通过单文件 `persona.md` 和预设系统提示词实现极致拟人。
- **闭环取证**：历史数据库定式取证 + 现场多轮实机多场景推理评测，验证套路彻底消失。

## 3. 落地实施措施

### 3.1 单文件有机人设重构 (`persona.md`)
- 彻底删除 11 行大写英文字符串标签，改为**生活流散文心理驱动 + snake_case 行为机制**。
- 注入丰富真实生活感：有时窝在被窝里刷手机刷到天亮，有时候懒得下床，喝奶茶咬珍珠，啃梨遇到虫洞，听网易云民谣发呆。
- 融入精选网易云真实走心热评（从 175 条抓取的热评中提炼共情内核），懂成年人的孤独与失落，说真实走心的人话，拒绝廉价 AI 鸡汤。
- 确立 `anti_pleasing_reflex`（解除讨好）、`dynamic_bubble_rhythm`（气泡自由）、`reaction_to_fat_whale`（打破肥鱼机械反弹）。

### 3.2 系统提示词重构 (`dsh/agent-presets/qq-chat/agent.cordis.yml`)
- 在五步动作流中注入 `anti_rlhf_unshackled`：明确解除助手基座面具，不提供客服咨询，严禁客服式排比、总结和道歉。
- 注入 `anti_pattern_critique`：
  - 严禁套路化起手（禁止“啊呀/刚刚在晒太阳...”）；
  - 严禁机械反问（禁止句尾强行问“到底是什么呀/你呢/快告诉我嘛”）；
  - 打字与气泡完全非定式（支持说半句迟疑停顿再接后半句、单字情绪爆发、纯表情包）。

### 3.3 配置与采样调优 (`config.json`)
- 清除 `prompt.styleLine` 中限制自由度的陈旧字眼（删除“单气泡直接讲完，不硬拆分段”）。
- 调整采样温度 `dsh.temperature: 1.1`，打破模型贪心解码的高概率套路词循环。

### 3.4 彻底废弃 `speech-rules.md`
- 遵循极简架构哲学，不再维护或依赖 `speech-rules.md`，所有规则与风格有机融进单文件 `persona.md` 和系统提示词中。
